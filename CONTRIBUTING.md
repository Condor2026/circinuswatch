# Contribuir a CircinusWatch

¡Gracias por tu interés! Aquí van las reglas del proyecto.

## Principios que NO se negocian

1. **100% pasivo.** Cualquier PR que añada escaneo activo de puertos, explotación o fuzzing será **rechazado**.
2. **Simetría narrativa.** El análisis narrativo debe permanecer balanceado. No se aceptan listas unilaterales.
3. **Sin geolocalización como señal de peligro.** El país de un servidor no es un indicador de riesgo.
4. **Sin claves en el código.**
5. **Disclaimer visible.** Cualquier PR que elimine o debilite los disclaimers será rechazado.
